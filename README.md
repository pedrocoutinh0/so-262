# so-262

Repositório da disciplina **SO-262** para organização das atividades de avaliação.

## Estrutura

```text
avaliacoes/
├── atividade-01/
├── atividade-02/
├── atividade-03/
├── atividade-04/
├── atividade-05/
├── atividade-06/
├── atividade-07/
├── atividade-08/
├── atividade-09/
└── atividade-10/
```

Cada pasta de atividade possui um arquivo `README.md` com a descrição da atividade. Inicialmente, os arquivos contêm uma descrição base e serão atualizados conforme as atividades forem definidas no Google Classroom.

## Regras de avaliação (resumo)

- Atividades no Google Classroom: **peso 1**
- Provas escritas: **peso 2**
- Provas práticas: **peso 3**
- Exercícios e atividades devem ser evidenciados no GitHub por meio de pastas/subpastas com `README.md`, arquivos-fonte e evidências de execução.
